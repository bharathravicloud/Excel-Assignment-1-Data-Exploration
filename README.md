# Excel-Assignment-1-Data-Exploration
## Project Overview
This project demonstrates basic data exploration and analysis using Microsoft Excel. The dataset contains product details such as Product ID, Product Name, Brand, Price, Quantity, and Category.
I used Excel formulas, logical functions, text functions, conditional functions, and Excel Table Formatting to organize and analyze the dataset.
## Excel Functions Used
- SUM – Calculate total product price
- COUNTA – Count the number of products
- AVERAGE – Calculate average product price
- MIN / MAX – Find minimum and maximum prices
- IF – Categorize products into High Price / Standard Price
- SUMIF – Calculate total price for Electronics products
- COUNTIF – Count products below $100
- LEFT – Extract Day from Product ID
- RIGHT – Extract Country Code
- MID – Extract Month from Product ID
